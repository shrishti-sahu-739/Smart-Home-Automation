# Smart Home Automation System

## About the Project
Smart Home Automation is a web-based project designed to help users monitor and control home appliances through a simple dashboard.

## Features
- Web-based appliance control interface
- PHP backend for handling device-related requests
- Appliance-related images and web pages
- Focus on convenience and energy efficiency

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- Arduino
- XAMPP

## Project Setup
1. Install XAMPP.
2. Copy the project folder into the `htdocs` directory.
3. Start Apache and MySQL from the XAMPP Control Panel.
4. Import the project database into phpMyAdmin when the SQL export is available.
5. Open the project through `http://localhost/MajorProject/`.

## Notes
This project was developed for educational purposes. Database setup may be required before all features work correctly.
